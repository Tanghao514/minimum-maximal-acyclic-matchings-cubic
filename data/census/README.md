# Cubic graph census

`canonical/` contains one headerless graph6 record per line for all connected
simple cubic isomorphism classes at orders 4, 6, 8, 10, 12, 14, and 16.

| Order | Records |
|---:|---:|
| 4 | 1 |
| 6 | 2 |
| 8 | 5 |
| 10 | 19 |
| 12 | 85 |
| 14 | 509 |
| 16 | 4,060 |
| Total | 4,681 |

These files were generated with nauty 2.9.3 `geng` and are the exact inputs to
the preserved Solver B/C benchmark. Their hashes are in the publication
environment JSON and `PUBLICATION_SHA256SUMS.txt`.
